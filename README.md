## Branch

- `main` (protected) — головна захищена гілка, напряму її не чіпаємо. Сюди заливаємо вже повністю готовий проєкт із `dev`.
- `dev` — основна робоча гілка. Від неї робимо свої гілки і сюди ж потім зливаємо готову роботу.
- `add/...` або `fix/...` — гілки під конкретні задачі (наприклад, додати новий компонент або пофіксити баг). Створюються від `dev` і вливаються назад у `dev` через Pull Request.
